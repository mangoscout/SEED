# Mini Project Code
cameraCalibration.py and angleDetection.py= Computer Vision team code

Purpose: The purpose of cameraCalibration.py is to calibrate the camera so that images captured by the system can be corrected for lens distortion. It does this by detecting the corners of a chessboard calibration pattern in multiple images and comparing their detected positions with their known real-world positions to compute the camera’s intrinsic matrix and distortion coefficients. These calibration parameters are saved to a file for later use. The purpose of angledetection.py is to detect an ArUco marker in the camera feed and calculate the horizontal angle between the camera and the marker. The program loads the saved calibration parameters to undistort incoming images, detects the marker, estimates its position relative to the camera using a pose estimation algorithm, and calculates the angle from this position. The computed angle is then displayed on both the live video feed and an attached LCD screen.

Organization: The two files are organized so that the camera calibration process is performed first and its results are reused by the angle detection program. The cameraCalibration.py file defines user settings such as camera index, chessboard pattern size, and the number of captures, then repeatedly captures frames from the camera and detects chessboard corners until enough valid images are collected. These points are used by OpenCV’s calibration functions to compute the camera matrix and distortion coefficients, which are saved to a file. The angledetection.py file then loads this calibration data, initializes the camera, LCD display, and ArUco marker detector, and continuously processes incoming frames. Each frame is undistorted using the calibration parameters, checked for markers, and if a marker is detected, its pose is estimated and the horizontal angle between the camera and the marker is calculated and displayed on both the video feed and the LCD.
