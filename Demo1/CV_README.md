# Mini Project Code
__.ion = Localization and Controls team code

Purpose: The purpose of this program is to calibrate a camera so that images captured by the system can be corrected for lens distortion. The program uses a chessboard calibration pattern to detect known reference points in multiple images, and by comparing the known positions of chessboard corners with their detected positions in the camera image, the program calculates the camera’s intrinsic parameters and distortion coefficients. These calibration parameters allow the system to correct distorted images and improve the accuracy of future algorithms. The calibration results are saved to a file so they can be reused without recalibrating the camera each time the system runs.

Organization: The code is organized into several main sections. First, user-defined settings specify parameters such as the camera index, chessboard pattern size, number of calibration captures, and file names for saving results. Next, helper functions are defined, such as the sharpness scoring function used to evaluate image quality. The program then prepares the object points representing the known coordinates of the chessboard corners. During execution, the main loop continuously captures frames and stores valid captures when the board has moved enough and enough time has passed since the previous capture. After the required number of frames is collected, the program performs camera calibration using OpenCV functions and computes the camera matrix and distortion coefficients. Finally, the results are saved to a file and an optional undistorted test image is generated to verify the calibration worked correctly.
